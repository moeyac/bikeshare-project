Project Title  
Explore US Bikeshare Data

Date Created  
January 13, 2026

Description  
This project uses Python to explore bikeshare data from three major US cities: Chicago, New York City, and Washington. The goal is to compute descriptive statistics and answer user-driven questions about the data. The script allows users to filter by city, month, and day of the week, then interactively view insights such as most common travel times, popular stations, trip durations, and user demographics.

Files Used  
- `bikeshare.py`: Main Python script containing all logic and interactive prompts  
- `README.md`: Project overview and instructions  
- `.gitignore`: Ensures `.csv` data files are excluded from version control  
- `GitCommands.pdf`: Documentation of all Git commands used during project setup and branching

Dataset  
The project uses randomly selected data from the first six months of 2017. Each city dataset includes the following columns:
- Start Time
- End Time
- Trip Duration
- Start Station
- End Station
- User Type  
Additional columns may include Gender and Birth Year depending on the city.
